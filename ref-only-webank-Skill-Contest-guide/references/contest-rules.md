| 名次 | Token 额度 |

## 常见问答

- **Q: Token 和积分可以都要吗？** 不行，二选一。
- **Q: 活动开始前上架的 Skill 算吗？** 不算，必须是活动期内新上架的 Skill。
- **Q: Token 一个月内没用完能延期吗？** 不能，有效期一个月，逾期作废。
- **Q: 积分是什么？** 微礼享积分，等同于钱，1 积分 = 1 元，800 积分即 800 元。
- **Q: 早鸟奖和人见人爱奖能同时拿吗？** 规则未明确说明，请咨询赛事联系人黄紫琳、莫彦斌确认。
