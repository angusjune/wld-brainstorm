## 适用情况

某个借款页 / 流程看着做好了，想在评审或汇报前做一次「正确性」检查 —— 数字算得对不对、同一屏的两个数值有没有打架、弹窗背景和它盖住的那屏是否一致、文案有没有写错。

## Prompt 示例

- `/fix-details https://figma.com/design/xxxx`
- `/fix-details [截图]`

## Agent 会做什么

1. 逐屏读取设计，把金额、利率、期数、文案逐项列出来
2. 跑 4 类检查：**A 计算正确性**（用插件自带的可运行计算器复算）/ **B 同屏一致** / **C 跨屏一致** / **D 文案**
3. 输出按严重度分级的报告（🔴 必改 / 🟡 建议改 / ❓ 待确认输入），每条给出修正值
4. 缺关键输入时会向你索要，而不是瞎猜一个数

计算口径：年利率换算日利率固定按 360 天年化。

## 依赖项

无 — 计算器随插件自带，`node` 直接可跑。
